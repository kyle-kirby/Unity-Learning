
# Unity Junior Programmer Pathway
Prototype 4 & Challenge 4

## 📌 Overview
This repository contains two projects completed as part of the Unity Junior Programmer Pathway:

- **Prototype 4:** Focused on implementing object spawning and managing game flow.
- **Challenge 4:** Built upon Prototype 4 concepts with additional mechanics and creative customization.

---

## ✅ What I Learned
### 1. Object Spawning & Prefabs
- How to instantiate objects dynamically using `Instantiate()`.
- Managing spawn positions and intervals with `InvokeRepeating()`.

### 2. Player Input & Movement
- Handling player input with `Input.GetKey()`.
- Restricting movement within boundaries using conditional checks.

### 3. Game State Management
- Implementing game-over logic to stop spawning and disable player controls.

### 4. Collision Detection & Level Increase
- Detecting collisions with `OnTriggerEnter()` for collecting items or avoiding obstacles.
- Updating score dynamically and displaying it on the UI.


---

## 🛠 Technologies Used
- **Unity (C# scripting)**
- Prefabs for reusable game objects
- Collision detection with triggers
