# Unity Junior Programmer Pathway  
Prototype 5 & Challenge 5  

📌 Overview  
This repository contains two projects completed as part of the Unity Junior Programmer Pathway:  

- **Prototype 5**: Focused on building and managing UI systems such as score displays, restart screens, and game flow.  
- **Challenge 5**: Expanded on Prototype 5 concepts with creative UI customization, additional feedback elements, and improved player experience.  

---

✅ What I Learned  
1. **UI Systems & Score Display**  
   - Creating UI text elements to show score and other game stats.  
   - Updating UI dynamically with `TextMeshPro` during gameplay.  

2. **Game Over & Restart Screens**  
   - Detecting player defeat and enabling restart/game over UI panels.  
   - Using `SceneManager.LoadScene()` to reset gameplay when restarting.  

3. **Game Flow Management**  
   - Controlling when the game is active or paused.  
   - Disabling player input and spawning when the game ends.  

4. **Player Feedback & Interaction**  
   - Providing clear visual cues through UI when the game state changes.  
   - Integrating simple feedback systems to improve clarity for the player.  

---

🛠 Technologies Used  
- Unity (C# scripting)  
- UI Canvas system  
- TextMeshPro for dynamic text updates  
- Scene Management with `SceneManager`  
- Restart and game over UI panels
